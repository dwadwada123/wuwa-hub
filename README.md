# Wuthering Waves Hub (WuWa Hub)

A personal, cloud-synced web application for **Wuthering Waves (Version 3.7 - Hsin / Suoming)** players:
- **Auto Team Builder & Synergy Engine**: Automatically creates optimal Hypercarry and Quickswap teams based on your owned Resonators.
- **Game8-style Rotation & Combo Guide**: Step-by-step combat combo instructions with Standard and Quickswap branches.
- **Tower of Adversity (ToA) Solver**: Dispatches 3 unique, non-overlapping teams for Hazard, Resonant, and Echoing Towers.
- **Convene / Pity Tracker**: 1-click PowerShell log import directly to Supabase cloud database.
- **Waveplate & Weekly Bosses Tracker**: Real-time stamina countdown and reset checklist.
- **Zero Local Database**: Powered by Supabase PostgreSQL.
