# Wuthering Waves — Combat Rotation System & Execution

A successful Wuthering Waves team relies on smooth Concerto generation, Outro-to-Intro handoffs, buff alignment, and animation canceling.

---

## 1. Core Rotation Principles

1. **Concerto Meter Management (100 Points)**:
   - When Concerto is full (100/100), swapping characters triggers the outgoing character's **Outro Skill** and the incoming character's **Intro Skill**.
   - Traditional supports take ~3-8 seconds to build Concerto.
   - 3.7 Unison characters (Hsin, Suoming) can bypass or compress this requirement via Unison Response.

2. **Standard Sequence Architecture**:
   `Support (Buffer/Sustain) ➔ Sub-DPS (Deepen Provider) ➔ Main DPS (Burst Window) ➔ Repeat`

---

## 2. Key Team Rotation Blueprints

### A. Hsin + Xiangli Yao / Suoming (Unison Electro)
1. **Shorekeeper**:
   - Cast Skill (E) for butterfly Forte ➔ Cast Liberation (R) to deploy Stella Field.
   - Activate Fallacy of No Return Echo ➔ Outro triggers Binary Butterfly (+12.5% Crit Rate, +25% Crit DMG).
2. **Hsin (Sub-DPS)**:
   - Enter via Intro ➔ Cast Skill (E) in Electro Flare ➔ Cast Liberation (R).
   - Consume Unison state ➔ Trigger Unison Response Outro immediately.
3. **Xiangli Yao / Suoming (Main DPS)**:
   - Enter via Unison Intro ➔ Activate Liberation (R) ➔ Execute enhanced Skill chains.
   - Cycle finishes in ~14 seconds.

### B. Camellya + Sanhua (Havoc Blossom Flurry)
1. **Shorekeeper / Verina**:
   - Intro ➔ E ➔ R ➔ Mid-air combo ➔ Rejuvenating Echo ➔ Outro.
2. **Sanhua**:
   - Intro receives buff ➔ Cast E (ice block) ➔ Cast R (ice spikes) ➔ Heavy Attack on blue timing bar (Detonate) ➔ Impermanence Heron Echo.
   - Concerto hits 100 in 3.2 seconds! ➔ Outro grants +38% Basic ATK Deepen for 14s.
3. **Camellya**:
   - Intro into field ➔ Activate Ephemeral Stance ➔ Hold Basic ATK for whip dance ➔ Cast Liberation (R) finisher.

### C. Jinhsi + Zhezhi / Yuanwu (Incandescence Burst)
1. **Verina / Shorekeeper**:
   - Opener buffs & healing field deployed.
2. **Zhezhi / Yuanwu**:
   - Yuanwu enters ➔ Drops Skill (E) Thunder Wedge (1 sec total on-field!) ➔ Bell-Borne Echo.
   - OR Zhezhi: Intro ➔ E ➔ R (ink cranes off-field coordinated attacks) ➔ Heron Echo ➔ Outro (25% Skill DMG Deepen).
3. **Jinhsi**:
   - Intro (Incarnation state) ➔ Incandescence fills to 50 stacks from coordinated hits ➔ Basic attacks ➔ Skill Phase 1 ➔ Liberation (R) ➔ Illuminous Epiphany dragon blast.
