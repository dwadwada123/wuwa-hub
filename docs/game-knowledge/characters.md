## 2. Standard 5-Star Resonators

- **Verina**: Universal Tier 0 buffer/healer. Outro gives 15% All-Type DMG Deepen for 30s. Photosynthesis mid-air combo gives near-instant Concerto.
- **Calcharo**: Electro Liberation Main DPS. Requires high field time. Synergizes with Yinlin / Jianxin.
- **Encore**: Fusion Basic ATK / Quickswap carry. Synergizes with Sanhua (38% Basic ATK) or Changli (Fusion quickswap).
- **Jianxin**: Aero Shielder / Parry / Crowd Controller. Outro gives 38% Resonance Liberation Deepen.
- **Lingyang**: Glacio Gauntlets aerial carry. Synergizes with Sanhua and Zhezhi.
- **Rover (Havoc)**: Top-tier F2P Havoc Main DPS. Synergizes with Danjin (+23% Havoc) and Sanhua.
- **Rover (Spectro)**: Spectro Sub-DPS / Time-Stop CC.
- **Rover (Aero)**: Aero Crowd Control & vortex vacuum.
