# Wuthering Waves — Version 3.7 Meta Teams & Team Compositions

This document outlines the core verified meta teams in Version 3.7, broken down by archetype, mechanics, strengths, and budget alternatives.

---

## 1. Premier Meta Teams (Version 3.7)

### Team 1: Mengzhou Unison Electro Core
- **Members**: Hsin (Quickswap DPS/Buffer) + Suoming / Xiangli Yao (Main DPS) + Shorekeeper / Verina (Universal Support)
- **Role Breakdown**:
  - Carry 1: Suoming / Xiangli Yao
  - Carry 2: Hsin (Sub-DPS / Unison enabler)
  - Sustain/Buffer: Shorekeeper (or Verina)
- **Mechanics**: Exploits 3.7 Unison response. Hsin applies Electro Flare and swaps into Suoming/Xiangli Yao with zero downtime.
- **Strengths**: Ultra-high burst, continuous rotation without Concerto dead zones, massive AoE & single-target DPS.
- **Weaknesses**: Requires high APM quickswapping; timing cancels is crucial.
- **F2P Alternative**: Replace Suoming with Calcharo or Lumi; replace Shorekeeper with Buling or Baizhi.

### Team 2: Camellya Havoc Blossom Hypercarry
- **Members**: Camellya (Main DPS) + Sanhua (Sub-DPS / Deepen) + Shorekeeper / Verina (Sustain / Buffer)
- **Role Breakdown**:
  - Main DPS: Camellya (Basic ATK Focus)
  - Sub DPS: Sanhua (38% Basic ATK Deepen, 3s concerto cycle)
  - Sustain: Shorekeeper / Verina
- **Mechanics**: Sanhua enters, uses E > R > Detonate (charges 100% Concerto in 3-4s), Outros to Camellya. Camellya enters with 38% Basic ATK Deepen + Shorekeeper's 12.5% Crit/25% Crit DMG, executes Ephemeral Stance whip flurry.
- **Strengths**: Highest sustained single-target & cleave DPS in the game; extremely fast and reliable rotation.
- **F2P Alternative**: Replace Shorekeeper with Baizhi; replace Sanhua with Danjin (+23% Havoc Deepen).

### Team 3: Jinhsi Sovereign Dragon Burst
- **Members**: Jinhsi (Main DPS) + Zhezhi / Yuanwu (Sub-DPS / Coordinated) + Shorekeeper / Verina (Sustain)
- **Role Breakdown**:
  - Main DPS: Jinhsi (Skill DMG / Incandescence)
  - Coordinated Enabler: Zhezhi (Skill DMG Deepen + coordinated birds) OR Yuanwu (Instant E column)
  - Sustain: Shorekeeper / Verina
- **Mechanics**: Zhezhi or Yuanwu provides rapid off-field coordinated hits of different elements, rapidly charging Jinhsi's 50 Incandescence stacks. Jinhsi unleashes Illuminous Epiphany dragon beam for massive single-instance nuke.
- **Strengths**: Unmatched single-hit burst damage; deletes boss phases instantly.
- **Weaknesses**: Missing Incandescence stacks heavily reduces output; strict stack monitoring.
- **F2P Alternative**: Yuanwu (Level 1 works because only E column is needed!) + Baizhi.

### Team 4: Changli & Encore Dual Fusion Quickswap
- **Members**: Changli (Quickswap Main DPS) + Encore (Quickswap Main DPS) + Shorekeeper / Verina (Sustain)
- **Role Breakdown**:
  - Carry 1: Changli (Fusion / Liberation buffer)
  - Carry 2: Encore (Basic ATK / Liberation carry)
  - Sustain: Shorekeeper
- **Mechanics**: Exploits animation canceling. Encore starts heavy attack charge (Cosmos Rave); player instantly swaps to Changli to perform True Sight combos while Encore finishes cast off-field.
- **Strengths**: Continuous high DPS with almost zero idle frames.
- **Weaknesses**: High skill ceiling; requires mastery of swap timing.

### Team 5: Jiyan Qingloong Whirlwind Storm
- **Members**: Jiyan (Main DPS) + Mortefi (Sub-DPS) + Shorekeeper / Verina (Sustain)
- **Role Breakdown**:
  - Main DPS: Jiyan (Heavy ATK scaling)
  - Sub DPS: Mortefi (+38% Heavy ATK Deepen, off-field dragon projectiles)
  - Sustain: Shorekeeper / Verina
- **Mechanics**: Mortefi's Outro specifically buffs Heavy ATK DMG by 38% for 14s. Jiyan's entire Liberation (Lance of Qingloong) is classified as Heavy ATK DMG.
- **Strengths**: Best AoE mob gathering and clearing in Tower of Adversity.

### Team 6: Rover (Havoc) Dark Surge F2P Powerhouse
- **Members**: Rover (Havoc) + Danjin / Sanhua + Baizhi / Verina
- **Role Breakdown**:
  - Main DPS: Rover (Havoc)
  - Sub DPS: Danjin (23% Havoc Deepen) or Sanhua (38% Basic ATK Deepen)
  - Sustain: Baizhi (15% All-Type Deepen via feather)
- **Strengths**: 100% F2P accessible (Rover S6 is free via story); rivals limited 5-star DPS in output.
- **Weaknesses**: Danjin consumes self-HP; vulnerable to one-shots if unshielded.
