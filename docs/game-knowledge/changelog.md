# Wuthering Waves — Historical Version Changelog & Evolution

This document tracks the version progression of Wuthering Waves, documenting major character, Echo, and mechanics shifts.

---

## Version 3.7 (2026-09-30) — Prism's Illusion, Heart's Illumination [LIVE]
- **Characters Added**: Hsin (Phase 1, 5★ Electro Rectifier), Suoming (Phase 2, 5★ Electro Sword).
- **Echoes / Sonatas Added**: Heart of Sworn Vigil 5-piece Sonata; Reminiscence: Suhsin the Inevitable (4-cost).
- **Core System Mechanic**: Unison system introduced, enabling instant Unison Response Intro transitions.
- **Meta Impact**: Dual-Electro and Unison quickswap setups emerge alongside established Camellya / Jinhsi teams.

## Version 3.6 (2026-08-15) — Historical
- Introduced Chisa and Iuno.
- Expanded Aero and Havoc hybrid options.

## Version 2.0 – 2.8 (2025) — Historical
- Introduced Black Shores arc (Shorekeeper, Camellya, Youhu, Lumi).
- Established Shorekeeper as the premier Crit buffer of the game.

## Version 1.0 – 1.4 (2024) — Historical
- Initial game launch (Jiyan, Yinlin, Jinhsi, Changli, Xiangli Yao, Zhezhi).
- Initial 5-star standards: Verina, Calcharo, Encore, Jianxin, Lingyang.
